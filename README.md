# R-Music Ops (@music-ops)

> 专职 AI 智能体：`@music-ops`
> 线上服务：`https://music.1234r.com`
> 部署服务器：日本东京基础设施节点 (`64.83.34.204`)

## 项目简介
`R-Music` 是将 **YesPlayMusic**（沉浸式高颜值网易云播放器）与 **go-music-dl**（全网10+平台聚合无损解析下载工具）进行深度整合的一体化智能音乐中枢系统。

### 核心特性
1. **一体化单容器架构 (All-in-One)**：
   - Nginx 反代入口 + Go 语言全网无损解析器 + Python 轻量 AI 意图分发器跑在同一个容器内；
   - 彻底避免跨容器网络通讯与端口暴露，极简运维。
2. **AI 自然语言搜索与点歌**：
   - 对接 `api.1234r.com` 大模型网关；
   - 支持语义模糊搜索、情绪场景化智能切歌。
3. **全网无损换源与下载**：
   - 网易云灰色版权歌曲自动调用 QQ/酷狗/酷我/B站 换源；
   - 支持 24bit FLAC 无损歌曲解析与本地持久化。
4. **全端自适应与毛玻璃质感**：
   - 零侵入式动态样式注入，不破坏前端升级；
   - 完美适配手机、平板、桌面与暗黑模式。
